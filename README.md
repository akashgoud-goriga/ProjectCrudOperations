# CRUD Operations Project

A simple and interactive **CRUD (Create, Read, Update, Delete) Application** built using HTML, CSS, and JavaScript.

This project allows users to add, view, update, and delete user information, including their photo, name, and email address. The data is stored in the browser's Local Storage, so it remains available even after refreshing the page.

## 🚀 Features

- **Create:** Add new users by entering their photo, name, and email through a form.
- **Read:** Display the list of all added users.
- **Update:** Edit existing user details whenever needed.
- **Delete:** Remove users from the list.
- **Local Storage:** Save user information in the browser's local storage.
- **Interactive UI:** Simple and user-friendly interface.
- **Form Handling:** Add and manage user details using a form.

## 🛠️ Technologies Used

- **HTML5** – To structure the application.
- **CSS3** – To style and enhance the user interface.
- **JavaScript** – To implement CRUD functionality and handle user interactions.
- **Local Storage** – To store user data in the browser.

## 📸 How It Works

1. Click the **Create User** button.
2. Fill in the required details, such as photo, name, and email.
3. Submit the form to add a new user.
4. View the added users on the screen.
5. Use the update option to modify user information.
6. Use the delete option to remove a user.
7. All user information is saved in Local Storage.
